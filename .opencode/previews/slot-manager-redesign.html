Design invariants preserved

  • • Esc closes innermost layer first (context menu → modal → main menu)
  • • h/j/k/l navigation contract unchanged
  • • KEY_RESIZE / SIGWINCH recompute layout — toolbar collapses, list scrolls, no hardcoded width
  • • No color-only signals — AVAILABLE/RESERVED are text pills + ◉ shape, not just color
  • • i18n — all strings go through i18n::tr() (en + es)
  • • Render-then-paint — button + row hitboxes built during draw
  • • Confirmation — Delete still requires explicit confirm (no silent data loss)
